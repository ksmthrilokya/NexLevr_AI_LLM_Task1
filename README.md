# Nexlevr Internship - AI & LLM Fundamentals

**Domain:** AI & LLM Fundamentals
**Task:** Beginner Task 1 - Prompt Engineering Template System

## About
This repository contains my submission for the Nexlevr AI & LLM Fundamentals internship (Sep 14 - Sep 30, 2026), Beginner Task 1.

## What I Built
A set of 5 prompt engineering templates designed to generate different styles of marketing copy:
1. Instagram Caption
2. Email Subject Line
3. Product Description
4. Advertisement Copy
5. Blog Post Title

Each template was tested using ChatGPT, and the results are included as screenshots in this repository.

## Files
- `prompt_templates.md` - The 5 prompt templates with filled-in examples
- `sc1.jpeg` to `sc6.jpeg` - Screenshots of each prompt tested with its AI-generated output
